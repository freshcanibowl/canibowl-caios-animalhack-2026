# Demo Guide

This guide describes the intended AnimalHack judge flow using synthetic data only.

## Judge Flow

### 1. Start with a synthetic pet

Create or select a sample pet profile. No real customer or pet-owner information is required.

### 2. Review the profile

Capture a small set of useful context:

- species
- age / life stage
- current weight
- activity level
- feeding pattern
- relevant observations

### 3. Add recent observations

Record example events such as:

- what the pet ate
- appetite changes
- stool observations
- weight changes
- body-condition observations
- behaviour notes

### 4. Run AI assistance

The system interprets the structured observations and produces an easy-to-understand nutrition and health-oriented summary.

The goal is to demonstrate the loop:

```text
DATA → INTERPRETATION → GUIDANCE → MONITORING
```

### 5. Review the result

A useful result should make it easy for a pet parent to understand:

- what changed
- what may be worth monitoring
- what feeding or lifestyle information is relevant
- when professional veterinary advice should be considered

### 6. Show the longitudinal concept

The same workflow can be repeated over time so that individual observations become a pet-health timeline rather than isolated records.

## Suggested Synthetic Pet

Use a fictional example such as:

**Name:** Milo  
**Species:** Dog  
**Age:** 4 years  
**Life stage:** Adult  
**Weight:** 12.5 kg  
**Activity:** Moderate  
**Recent observation:** Appetite slightly reduced for two days; stool softer than usual.

This example is intentionally synthetic and should not be treated as a real clinical case.

## Demo Principle

The hackathon demo should prove the product workflow, not claim that AI can diagnose disease.

CaniBowl's intended direction is to combine fresh-food nutrition, structured health data, community knowledge, and personalised assistance while keeping veterinary professionals in the loop for medical decisions.
